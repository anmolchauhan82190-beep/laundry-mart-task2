# Laundry Wallah / Laundry Mart

A simple static HTML webpage for a laundry and dry-cleaning service, built as part of Task 2 (HTML) for the MERN Stack course.

# Features
- Welcome heading and about section describing the service
- Laundry-themed image
- "Our Services" section listing services offered (Washing & Drying, Ironing & Folding, Dry Cleaning, Stain Removal, Express Service, Special Garment Care, and more)
- Price List table showing service rates
- "Book Now" form to collect Name, Email, and Phone
- Contact information section

# How to Run
1. Download or clone this folder.
2. Open `index.html` in any web browser (double-click the file, or use Live Server in VS Code).
